
# Projeto Backend - Biblioteca

Este é um backend para gerenciar uma biblioteca, com funcionalidades de **livros**, **autores**, **leitores** e **auditórios**. O projeto utiliza **Node.js**, **Express**, **TypeORM** com banco de dados PostgreSQL e possui funcionalidades de CRUD (Create, Read, Update, Delete).

## Tecnologias

- **Node.js** - Ambiente de execução JavaScript do lado do servidor.
- **Express** - Framework web para Node.js.
- **TypeORM** - ORM para interagir com o banco de dados PostgreSQL.
- **PostgreSQL** - Banco de dados relacional.
- **CORS** - Para permitir requisições de diferentes origens.
- **Reflect-Metadata** - Para o uso de metadados no TypeORM.

## Pré-requisitos

Antes de rodar o projeto, é necessário ter o **Node.js** e o **PostgreSQL** instalados em sua máquina.

### Instalação do Node.js

Se você não tem o Node.js instalado, acesse: [Node.js](https://nodejs.org/) e siga as instruções de instalação para o seu sistema operacional.

### Instalando o PostgreSQL

Siga o tutorial no site oficial para instalar o PostgreSQL: [PostgreSQL](https://www.postgresql.org/download/).
